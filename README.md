# Laba2

Лабораторная работа №2. Циклы с предусловием и постусловием

**Вариант 7**

## Описание задачи
Программа вычисляет остаточное давление газа в камере после работы поршневого насоса. 
Расчет ведется по формуле: p = p0 * (V / (V + V0))^n

Таблица значений строится на двух участках:
1. Первый участок (n = 10..50, шаг 10) рассчитывается с помощью цикла с постусловием `do while`.
2. Второй участок (n = 100..250, шаг 50) рассчитывается с помощью цикла с предусловием `while`.

## Входные данные
При запуске программа запрашивает следующие параметры:
* `p0` — начальное давление, например: 760
* `V` — объем камеры (в литрах), например: 15
* `V0` — рабочий объем насоса (в литрах), например: 0.6
